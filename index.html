Sobre

ComprasMatch — Visão Geral

Sistema para análise de similaridade de itens de compras públicas do PNCP: busca, embeddings e visualização de grafos.

Busca de Itens

Consulta ao PNCP para recuperar itens públicos por ano.

Embeddings

Geração de embeddings com `EmbeddingGemma` para comparação semântica entre as descrições dos itens.

Grafo de Similaridade

Visualização interativa de grafos para indentificação dinamica de similaridades.

Interface Web

Aplicação em `Flask` para navegação de itens, busca e análise de similaridades.

Sobre o ComprasMatch

O ComprasMatch usa inteligência para identificar quando diferentes órgãos públicos estão contratando itens parecidos. A ideia é “dar o match” entre essas contratações e incentivar compras compartilhadas, que ainda são pouco usadas, mas trazem grandes ganhos de escala e economia.

Com o ComprasMatch, cada órgão recebe um alerta quando existir uma contratação similar acontecendo em outro lugar — facilitando parceria, reduzindo custos e tornando as compras públicas muito mais eficientes.
